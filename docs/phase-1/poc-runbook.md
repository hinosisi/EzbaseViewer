# 엔진 PoC 실행서

## 준비

- 격리된 Windows 10/11 x64 시험 PC 또는 VM
- 관리자 PC 2대, 호스트 4대 이상
- 사내망과 서로 다른 인터넷 회선 2개
- 표준 사용자·관리자 사용자, 다중 모니터 1대 이상
- 패킷 메타데이터·CPU·GPU·메모리·대역폭 측정 수단
- 후보별 평가판/SDK와 분석·재배포 권한 문서

## 실행 순서

1. 설치 파일의 버전, 서명자, SHA-256, 획득 URL을 기록한다.
2. 기본 설정으로 Viewer·Host·조정·중계 구성요소와 프로세스 트리를 기록한다.
3. 같은 사내망, 서로 다른 인터넷 회선에서 접속한다.
4. 직접 경로를 차단하고 제한 시간, 오류, 중계 전환 여부를 기록한다.
5. 일반 데스크톱, UAC 보안 데스크톱, 잠금·로그온 화면에서 보기와 입력을 시험한다.
6. 사용자 전환·로그오프·서비스 재시작·PC 재부팅을 수행한다.
7. 다중 모니터 전환과 서로 다른 DPI·해상도를 시험한다.
8. 1GB 파일과 다수 소파일을 양방향 전송하고 SHA-256을 비교한다.
9. 무인 접속 허용·철회, 현장 종료, 관리자 종료 후 재접속을 시험한다.
10. 8시간 연속 세션, 반복 연결 100회를 수행한다.
11. Ezbase 제어 서버의 사용자·업체·기능 권한을 엔진에 적용할 수 있는 지점을 확인한다.
12. Host 빌드에 Viewer·대상 검색·접속 시작 기능이 포함되지 않았는지 확인한다.
13. 증거를 검토하고 필수 게이트와 점수를 승인한다.

## 중단 기준

- 허가되지 않은 대상 파일이나 라이선스 우회가 필요해진 경우
- 회사 시험 계정 밖의 제3자 시스템으로 트래픽이 전송되는 경우
- UAC·로그온 화면 시험이 업체 PC 보호 설정을 약화해야만 성공하는 경우
- 실행 파일 서명 또는 공급 경로를 확인할 수 없는 경우

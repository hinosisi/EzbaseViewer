## 현재 게이트

- 화면 데이터 경로 개발은 엔진 필수 게이트와 배포 조건이 확정될 때까지 시작하지 않는다.
- Ezbase 사용자 지정 URI와 필드명은 Ezbase 기술 담당자의 실제 인터페이스가 제공될 때까지 제안 상태로 유지한다.
- `AuditTrail`, 장치·토큰 저장소는 프로세스 메모리 기반이다. DB 선택 전 기능 계약을 검증하기 위한 구현이며 운영에 사용할 수 없다.

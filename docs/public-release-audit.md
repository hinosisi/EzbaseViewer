## 공개 전 남은 작업

1. 저장소의 비공개 보안 제보 기능 또는 실제 보안 연락처 설정
2. 보호 브랜치, 필수 검토, 비밀정보·의존성·라이선스 자동 검사 구성
3. 첫 원격 푸시 직전에 Git 전체 이력 재검사

새 로컬 Git 저장소를 `main` 브랜치로 초기화했다. 기존 커밋 이력이 없으므로 과거 이력 유출 위험은 없으며, 첫 커밋과 원격 공개 직전에 스테이징된 파일을 다시 검사한다.
